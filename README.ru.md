# Pac-Man Mini Game

[English](README.md) · [Русский](README.ru.md)

Лёгкая браузерная мини-игра в стиле Pac-Man. Её удобно показывать пользователю, пока обрабатывается задача.

## Возможности

- Плавное движение Pac-Man и призраков
- Управление с клавиатуры (стрелки и WASD)
- Очки, жизни, победа и поражение
- Быстрый перезапуск без перезагрузки страницы
- Без зависимостей: чистые HTML, CSS и JavaScript

## Управление

- `ArrowUp` / `W` — вверх
- `ArrowDown` / `S` — вниз
- `ArrowLeft` / `A` — влево
- `ArrowRight` / `D` — вправо
- `R` — новая игра

## Начало работы

Откройте `index.html` в браузере или запустите локальный сервер (рекомендуется):

```bash
python3 -m http.server 8080
```

Затем откройте <http://localhost:8080>.

## Структура проекта

- `index.html` — разметка игры и HUD
- `styles.css` — стили интерфейса и игрового поля
- `game.js` — логика игры, ИИ призраков, рендер и игровой цикл
